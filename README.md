# 咲 Midiplayer v3.5.3 - 60/88 键 MIDI 自动演奏器

将标准 MIDI 文件转换为键盘操作，用于在游戏星痕共鸣中自动演奏。

当前版本已从早期 36 键方案扩展为：

- **经典 60 键模式**：36 个物理键 × 多模式切换，覆盖 `C2-B6`
- **扩展 88 键模式**：通过扩展模式覆盖更完整钢琴音域 `A0-C8`
- **三套界面**：Old UI、SAO Entity UI、SAO WebView UI

## 功能概述

- 支持标准 MIDI 文件（.mid / .midi）及自定义 JS 格式
- 经典模式支持 `normal / SHIFT / CTRL` 三种音区切换，覆盖 `C2-B6`
- 扩展模式支持 `LT / GT` 扩展切换，覆盖接近完整 88 键钢琴范围
- 36 键全音阶物理布局（含黑键/半音），支持 60 键 / 88 键映射
- 自动调性检测与移调，最大化音符覆盖率
- C 调直转模式：将任意调直接映射到 C 大调，无需半音偏移
- 延音模拟：读取 MIDI 踏板数据，用 `Space` 按下/释放模拟游戏踏板
- 连音衔接：音符之间智能重叠，旋律线条连贯如歌唱
- 人性化演奏：随机时机偏移、力度差异、琶音展开，模拟真人弹奏
- 钢琴家模拟：力度映射时长、音区表情差异、弹性速度（rubato）、乐句呼吸
- 熟练度系统：记录每首曲子的播放次数，随熟练程度减少犹豫延迟
- 智能和弦简化：音符过多时自动保留根音、五度音、高音旋律
- 音部控制：可独立开关高音旋律部与低音伴奏部，调整伴奏密度
- 三套界面：
	- `Old UI`：传统 Tk 窗口
	- `SAO Entity UI`：实体悬浮 HP + SAO 菜单
	- `SAO WebView UI`：WebView 透明悬浮窗 + 面板系统
- 全局快捷键：F5 播放/暂停、F6 停止、F7/F8 调速、F9 窗口置顶、F10 面板显隐

## 当前版本键盘布局

### 经典模式（60 键）

物理键仍为 36 键，但通过模式切换扩展音域：

- `normal`：`C3-B5`
- `SHIFT`：`C4-B6`
- `CTRL`：`C2-B4`

```
音区        简谱音         物理按键               MIDI 范围
高音白键    1̇ 2̇ 3̇ 4̇ 5̇ 6̇ 7̇   Q W E R T Y U        C5-B5 (普通) / C6-B6 (SHIFT)
高音黑键    #1̇ #2̇ #4̇ #5̇ #6̇  I O P [ ]
中音白键    1 2 3 4 5 6 7   A S D F G H J        C4-B4 (普通) / C5-B5 (SHIFT)
中音黑键    #1 #2 #4 #5 #6  6 7 8 9 0
低音白键    1̣ 2̣ 3̣ 4̣ 5̣ 6̣ 7̣   Z X C V B N M        C3-B3 (普通) / C4-B4 (SHIFT)
低音黑键    #1̣ #2̣ #4̣ #5̣ #6̣  1 2 3 4 5
```

### 扩展模式（88 键）

- `< / >` 方向扩展模式可向低音或高音进一步扩展
- 目标覆盖范围约为 `A0-C8`
- 适合高覆盖率演奏与更完整钢琴谱适配

## 安装与运行

**依赖环境：Python 3.8+**

```bash
pip install -r requirements.txt
python setup_cython.py build_ext --inplace  # 可选: LinkStart Canvas 回退加速
python main.py
```

Windows 下需以**管理员身份**运行，才能模拟键盘输入。

## 使用说明

1. 启动程序后选择你要使用的 UI 模式（Old / SAO Entity / SAO WebView）
2. 点击“打开 MIDI”选择文件，程序会自动分析调性并计算最优移调
3. 切换到游戏窗口后，按 `F5` 开始播放
4. 播放中可随时按 `F5` 暂停/继续，`F6` 停止，`F7/F8` 调节速度
5. 可手动微调移调（半音/八度）、切换模式系统或开启 C 调直转模式
6. 可按需开启钢琴面板、可视化、状态面板、控制面板
7. 支持文件夹循环播放与排行榜/角色成长系统

## 主要参数（config.py / player.py）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `KEY_DURATION_MIN` | 0.02 | 音符键最短短按时长 (20ms) |
| `KEY_DURATION_MAX` | 0.15 | 音符键最长短按时长 (150ms) |
| `LONG_SUSTAIN_PEDAL_ENABLED` | True | MIDI CC64 踏板用 Space 按下/释放模拟 |
| `SUSTAIN_SCALE` | 0.72 | 音符短按基础缩放 |
| `SUSTAIN_OVERLAP_MS` | 35 | 连音重叠时长 (ms)，最终仍限制在150ms内 |
| `MAX_SIMULTANEOUS_KEYS` | 1 | 最大同时按住的音符键数 |
| `MAX_STAGGERED_KEYS_PER_EVENT` | 5 | 同一时刻音群最多保留几个音并错开短按 |
| `MAX_NOTE_PRESSES_PER_SECOND` | 5 | 全局每秒最多按下几个音符键 |
| `PIANO_RUBATO_LONG_STRETCH` | 1.22 | 长音符弹性拉伸系数 |
| `HUMANIZE_TIMING_MS` | 30 | 时机随机偏移范围 (ms) |

## 注意事项

- 需要**管理员权限**才能模拟键盘输入
- 播放时游戏窗口需保持在前台（或开启窗口置顶）
- 经典模式可覆盖 `C2-B6`，扩展模式可覆盖接近完整钢琴音域
- 极高/极低音符会根据当前模式自动折叠或重映射到可用范围
- MIDI 踏板数据默认会转换为游戏内 `Space` 踏板的按下/释放；可在设置中关闭“Space长按踏板”
- 音符键始终按 20-150ms 短按输出；“连音重叠”只在这个范围内做小幅衔接
- 同一时刻多个音会按音高错开短按，尽量保持任意时刻只有一个音符键被按住
- 全局强制限制音符键按下速率为每秒最多 5 个，`Space` 踏板和模式切换键不计入
- WebView UI 需要系统可用的 WebView2 / Edge Chromium 环境
