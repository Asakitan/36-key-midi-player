# 咲Midiplayer - 36键位 MIDI 自动演奏器

将标准 MIDI 文件转换为 36 键虚拟电子琴的键盘操作，用于在游戏（如《光遇》《Sky》等）中自动演奏。

## 功能概述

- 支持标准 MIDI 文件（.mid / .midi）及自定义 JS 格式
- 36 键全音阶布局（含黑键/半音），覆盖 C3-B6 四个八度（48 个半音）
- SHIFT 模式一键切换八度，普通模式 C3-B5，SHIFT 模式 C4-B6
- 自动调性检测与移调，最大化音符覆盖率
- C 调直转模式：将任意调直接映射到 C 大调，无需半音偏移
- 延音模拟：读取 MIDI 踏板数据延长按键时长，不按游戏踏板键
- 连音衔接：音符之间智能重叠，旋律线条连贯如歌唱
- 人性化演奏：随机时机偏移、力度差异、琶音展开，模拟真人弹奏
- 钢琴家模拟：力度映射时长、音区表情差异、弹性速度（rubato）、乐句呼吸
- 熟练度系统：记录每首曲子的播放次数，随熟练程度减少犹豫延迟
- 智能和弦简化：音符过多时自动保留根音、五度音、高音旋律
- 音部控制：可独立开关高音旋律部与低音伴奏部，调整伴奏密度
- 全局快捷键：F5 播放/暂停、F6 停止、F7/F8 调速、F9 窗口置顶

## 键盘布局

```
音区        简谱音         物理按键               MIDI 范围
高音白键    1̇ 2̇ 3̇ 4̇ 5̇ 6̇ 7̇   Q W E R T Y U        C5-B5 (普通) / C6-B6 (SHIFT)
高音黑键    #1̇ #2̇ #4̇ #5̇ #6̇  I O P [ ]
中音白键    1 2 3 4 5 6 7   A S D F G H J        C4-B4 (普通) / C5-B5 (SHIFT)
中音黑键    #1 #2 #4 #5 #6  6 7 8 9 0
低音白键    1̣ 2̣ 3̣ 4̣ 5̣ 6̣ 7̣   Z X C V B N M        C3-B3 (普通) / C4-B4 (SHIFT)
低音黑键    #1̣ #2̣ #4̣ #5̣ #6̣  1 2 3 4 5
```

## 安装与运行

**依赖环境：Python 3.8+**

```bash
pip install -r requirements.txt
python main.py
```

Windows 下需以**管理员身份**运行，才能模拟键盘输入。

## 使用说明

1. 点击"打开 MIDI"选择文件，程序自动分析调性并计算最优移调
2. 切换到游戏窗口后，按 F5 开始播放
3. 播放中可随时按 F5 暂停/继续，F6 停止，F7/F8 调节速度
4. 可在 GUI 中手动微调移调（半音/八度）或开启 C 调直转模式
5. 拖动进度条或输入时间可跳转至指定位置

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| F5 | 播放 / 暂停 |
| F6 | 停止 |
| F7 | 加速 |
| F8 | 减速 |
| F9 | 窗口置顶切换 |

## 主要模块

| 文件 | 说明 |
|------|------|
| `main.py` | 程序入口 |
| `gui.py` | Tkinter 图形界面 |
| `player.py` | 播放控制、键盘模拟、延音/连音/人性化逻辑 |
| `midi_parser.py` | MIDI 解析、调性检测、和弦识别 |
| `keyboard_mapper.py` | MIDI 音符到按键的映射管理 |
| `config.py` | 所有可调参数集中配置 |

## 主要参数（config.py / player.py）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SUSTAIN_SCALE` | 1.28 | 基础延音倍率 |
| `SUSTAIN_OVERLAP_MS` | 200 | 连音重叠时长 (ms) |
| `SUSTAIN_PEDAL_BOOST` | 1.85 | 踏板踩下时的时长加成倍率 |
| `PIANO_HIGH_SUSTAIN` | 1.18 | 高音区时长倍率 |
| `PIANO_RUBATO_LONG_STRETCH` | 1.14 | 长音符弹性拉伸系数 |
| `HUMANIZE_TIMING_MS` | 30 | 时机随机偏移范围 (ms) |
| `MAX_SIMULTANEOUS_KEYS` | 8 | 最大同时按键数 |

## 注意事项

- 需要**管理员权限**才能模拟键盘输入
- 播放时游戏窗口需保持在前台（或开启窗口置顶）
- 四个八度（48 个半音）可覆盖绝大多数曲目；极高/低音符会自动折叠到可用范围
- MIDI 踏板数据会被读取并转换为按键时长加成，不会按游戏内的踏板键

## 打包为 EXE

```bash
pyinstaller build.spec --clean
```

输出位于 `dist/36键MIDI播放器.exe`，需要管理员权限运行。
