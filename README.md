# 28键电子琴 MIDI播放器

将MIDI文件转换为28键虚拟电子琴的按键操作，用于在游戏中自动演奏。

## 功能特点

- 📁 支持标准MIDI文件(.mid, .midi)
- 🎹 28键电子琴布局映射
- 🎵 自动移调优化覆盖率
- ⏯️ 播放/暂停/停止控制
- ⚡ 可调节播放速度(0.25x - 2.0x)
- 🎼 实时显示当前播放音符
- 📊 音符覆盖率分析

## 键盘布局

```
第1行 (高音):    1̇  2̇  3̇  4̇  5̇  6̇  7̇    -> 键盘: 1 2 3 4 5 6 7
第2行 (中高音):  1  2  3  4  5  6  7    -> 键盘: Q W E R T Y U
第3行 (中音):    1̣  2̣  3̣  4̣  5̣  6̣  7̣    -> 键盘: A S D F G H J
第4行 (和弦):    C Dm Em F  G Am G7   -> 键盘: Z X C  V B N  M
```

## 安装

### 1. 安装Python
确保已安装Python 3.7+

### 2. 安装依赖
```bash
cd 28midi
pip install -r requirements.txt
```

### 3. 运行程序
```bash
python main.py
```

## 使用说明

1. **打开MIDI文件**: 点击"打开MIDI"按钮选择文件
2. **自动移调**: 程序会自动计算最佳移调以提高音符覆盖率
3. **开始播放**: 点击"播放"按钮
4. **切换窗口**: 在播放开始前/后切换到游戏窗口
5. **调节速度**: 使用滑块或+/-键调节播放速度

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Space | 播放/暂停 |
| Escape | 停止 |
| +/= | 加速 |
| - | 减速 |

## 模块说明

| 文件 | 功能 |
|------|------|
| `main.py` | 主程序入口 |
| `gui.py` | 图形用户界面 |
| `player.py` | 播放控制、键盘模拟 |

| `keyboard_mapper.py` | 音符到按键映射 |
| `config.py` | 配置参数 |

## 注意事项

1. **管理员权限**: Windows下可能需要以管理员身份运行才能模拟按键
2. **窗口焦点**: 播放时需要将游戏窗口置于前台
3. **音符覆盖**: 28键只能覆盖部分音符，复杂MIDI可能无法完美播放
4. **移调调整**: 如果自动移调效果不好，可以手动调整

## 故障排除

### 按键没有反应
- 检查是否以管理员身份运行
- 确认游戏窗口是否处于激活状态
- 检查键盘映射是否与游戏设置一致

### MIDI加载失败
- 确认文件是标准MIDI格式
- 尝试用其他MIDI播放器验证文件

### 覆盖率太低
- 使用"自动调整"功能
- 手动尝试不同的移调值
- 考虑使用音域更合适的MIDI文件

## 自定义

### 修改键盘映射
编辑 `config.py` 中的 `KEYBOARD_LAYOUT` 和 `MIDI_TO_KEY`

### 修改按键时长
编辑 `config.py` 中的 `KEY_PRESS_DURATION`
